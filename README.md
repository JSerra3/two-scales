# Two Scales, One Answer

**Live:** https://jserra3.github.io/two-scales/

A system of two equations, solved by elimination on an apothecary balance scale.

1. **Fill the first scale.** Each side of the first equation goes into a pan: jars for x and y, pouches and vials for the numbers. The scale stands level, because the equation is true.
2. **Bring in the second scale.** The second equation gets a scale of its own, also level.
3. **Pour the second scale into the first.** Left pan into left pan, right into right. Equal weights are added to both sides, so the first scale stays level. The empty second scale reads 0 = 0 and gets thrown out.
4. **Cancel.** A term and its opposite in the same pan annihilate each other in close-up.
5. **Combine like terms.** One scale, one unknown, and the answer.

Every step is written down in the worked solution as it happens.

## Using it

- Pick a system from the card, or type your own (x and y only, whole numbers).
- **Next** (→ or Space) makes the next move. **Back** (←) takes it back.
- **R** starts over and **F** goes full screen. Click the system in the corner to change it.
- Link straight to a system: `?a=2x+y=11&b=x-y=1`

The whole page is one self-contained `index.html`. It works from this site, from a downloaded copy, or offline.
